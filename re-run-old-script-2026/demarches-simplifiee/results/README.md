# Résultats générés

L'orchestrateur écrit ici les scripts prêts à coller dans Chrome :

- `run_extract_product_photos.js`
- `run_extract_complete_dossiers.js`

Ces fichiers sont régénérables à partir de `data/dossier-id.txt`.

Ils contiennent les identifiants de dossiers locaux et sont ignorés par Git.
Les CSV filtrés peuvent aussi contenir des URLs temporaires de téléchargement ;
ils ne doivent pas être ajoutés au dépôt.
